Selected research

AUG 2024 – NOV 2025 · RESEARCH PROJECT

Parsec: A Two-Party Secure Database

A secure database system for privacy-preserving queries over distributed data, using standard two-party computation without a trusted third party.

  • Designed a modular architecture separating MPC primitives from relational database operators.
  • Improved system performance through parallel execution and secure network optimizations.
  • Studied and optimized cryptographic protocols for database workloads.
View project on GitHub
SEP – OCT 2024 · PREPRINT

Learned Indexes for Privacy-Preserving Databases

A learned index framework that uses machine learning to accelerate query processing under differential privacy constraints.

  • Optimized differentially private cumulative distribution functions for model training.
  • Implemented and evaluated piecewise linear regression and dual-layer neural network index models.
