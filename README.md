# Du Jianzhang — Personal Website

A responsive academic homepage prepared for GitHub Pages. No installation or build step is needed.

## 在 GitHub 上发布

1. 登录 GitHub 的 `uu60` 账号。
2. 新建公开仓库 `uu60.github.io`。如果同名仓库已存在，先检查原内容，避免覆盖。
3. 将本文件夹内的 `index.html`、`cv.pdf` 和 `.nojekyll` 上传到仓库根目录，不要把外层文件夹整体套进去，也不要只上传 ZIP。
4. 在仓库 Settings → Pages 中选择 Deploy from a branch，然后选择 `main` 和 `/ (root)`，保存。
5. 等待 GitHub 完成发布。届时地址为 https://uu60.github.io/ 。

## 修改内容

- `index.html`：网页内容与样式，可直接用文本编辑器修改。
- `cv.pdf`：简历下载，替换同名文件即可更新。
- `.nojekyll`：让 GitHub Pages 直接发布静态文件。

内容根据用户提供的简历整理；研究标题是网页描述性标题。没有补充未经提供的论文录用情况或成果指标。网页未展示电话号码，下载的 PDF 保留原始简历内容。发布前可按需更新简历中的任职时间和研究状态。
